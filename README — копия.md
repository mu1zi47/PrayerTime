# Flutter UI Kit и дизайн-система

Рабочая реконструкция по доступным сообщениям из чата «ИИ дизайн примеры».
Исходный README на 450 строк недоступен. Для реализации визуальных деталей
используйте утверждённый макет или исходные токены проекта.

## Визуальные параметры

| Область | Что сверить с утверждённым UI |
| --- | --- |
| Цвета | Значения палитры и назначение цветов фона, текста, действий и состояний |
| Радиусы | Значения для карточек, кнопок и нижней панели отметки |
| Типографика | Семейство, размеры, насыщенность и высота строки для времени, заголовков и подписей |
| Отступы | Поля экрана, интервалы между секциями и внутренние отступы компонентов |
| Анимации | Переходы между экранами и открытие нижней панели |

Точные значения этих параметров в доступной переписке отсутствуют.
Возьмите их из утверждённого источника перед обновлением темы.

## Компоненты и поведение

### Верхняя панель

Название текущего города открывает выбор города. Иконка настроек открывает
настройки приложения. На главной нет нижней навигации, крупной даты над
следующим намазом и колокольчика.

### Следующий намаз

Блок показывает название, время и обратный отсчёт. Указание «Сегодня» или
«Завтра» помогает понять, к какому дню относится время, в том числе при
переходе к завтрашнему Фаджру после Иши.

### Быстрый доступ и каталог

На главной ровно три настраиваемые кнопки. Нажатие сразу открывает
соответствующий инструмент. Ссылка «Все» в заголовке открывает отдельный
экран «Все инструменты» с группировкой по назначению.

Действие «Настроить» в верхней части каталога открывает выбор и изменение
порядка трёх инструментов. Изменения применяются после нажатия «Сохранить».
Кибла становится доступной после реализации.

Действие «Назад» возвращает к источнику перехода: в каталог или на главную.

### Расписание и отметки

Расписание на сегодня включает пять намазов и восход. Ссылка «На месяц» в
заголовке открывает месячное расписание. Главная прокручивается целиком,
строки не перекрываются плавающими панелями.

Нажатие на строку намаза открывает нижнюю панель с тремя действиями:
отметить вовремя, отметить с опозданием или удалить отметку. После выбора
панель закрывается, а строка обновляется. Восход отображается как
информационная строка.

## Правила для Flutter-разработчика

- Сохранить существующие функции и настройки при переработке интерфейса.
- Сверять тему, оформление компонентов и движения с утверждённым UI.
- Согласовать оформление списка расписания и детали второстепенных экранов
  перед их реализацией.
- Сохранить порядок главного экрана: город и настройки, следующий намаз,
  быстрый доступ, расписание.
- Проверить маленький экран, возврат из инструмента по обоим маршрутам,
  сохранение порядка быстрых действий, переход к завтрашнему Фаджру и все
  три действия отметки.
