# Публикация в Google Play — что делать

Всё, что можно было сделать в коде, уже сделано (см. «Что уже готово» ниже).
Осталось то, что требует ваших паролей и вашего аккаунта.

## 1. Создать ключ подписи (один раз, 2 минуты)

Ключ подписывает все ваши сборки. **Потеряете его — не сможете обновлять
приложение**, придётся публиковать заново под другим именем. Храните копию
в надёжном месте (не в этом репозитории).

```bash
keytool -genkey -v -keystore ~/prayertime-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

Спросит пароль и данные (имя, организация — можно свои, страна: UZ).

Затем скопируйте `android/key.properties.example` в `android/key.properties`
и впишите туда пароли и путь к файлу `.jks`. Этот файл в `.gitignore`,
в репозиторий он не попадёт.

## 2. Собрать бандл для загрузки

```bash
flutter build appbundle --release
```

Готовый файл: `build/app/outputs/bundle/release/app-release.aab`

Проверить, что он подписан вашим ключом, а не отладочным:

```bash
unzip -p build/app/outputs/bundle/release/app-release.aab META-INF/*.RSA | keytool -printcert
```

## 3. Зарегистрировать аккаунт разработчика

https://play.google.com/console → регистрация. Нужны: аккаунт Google,
удостоверение личности, банковская карта.

## 4. Создать приложение в Play Console

«Создать приложение» → название, язык, тип «Приложение», «Бесплатное».

Дальше по разделам:

- **Основные данные о приложении** — тексты из `store/listing.md`
- **Значок** — `store/icon-512.png`
- **Картинка функции** — `store/feature-graphic-1024x500.png`
- **Скриншоты телефона** — всё из `store/screenshots/` (их 5, минимум нужно 2)
- **Политика конфиденциальности** — ссылка (см. пункт 5)
- **Безопасность данных** — ответы в конце `store/listing.md`
- **Возрастной рейтинг** — анкета, ответы там же
- **Категория** — Образ жизни

## 5. Опубликовать политику конфиденциальности

Play требует ссылку на страницу в интернете. Готовый файл:
`docs/privacy-policy.html`. Бесплатный способ — GitHub Pages: залейте репозиторий
на GitHub, в Settings → Pages выберите ветку `main` и папку `/docs`, и через
пару минут страница будет доступна по адресу вида
`https://<ваш-логин>.github.io/<репозиторий>/privacy-policy.html`.

## 6. Закрытое тестирование (обязательный этап)

Для новых персональных аккаунтов Google требует: **не меньше 12 тестеров,
которые держат приложение установленным 14 дней подряд**, и только потом
открывается доступ к публикации. Тестеров приглашают по email или ссылкой
в разделе «Тестирование» → «Закрытое тестирование».

Если аккаунт оформлен как организация (юрлицо), этого требования нет.

## 7. Отправить на проверку

«Рабочая версия» → загрузить `.aab` → заполнить «Что нового» → отправить.
Первая проверка обычно занимает от нескольких часов до нескольких дней.

## Что уже готово в проекте

- `applicationId` изменён с шаблонного `com.example.prayertime` на
  **`uz.mu1zi47.prayertime`** (Play не принимает `com.example.*`).
  Пакет Kotlin, канал связи с виджетом и intent-экшены переименованы следом.
- Подпись релиза читается из `android/key.properties`; без этого файла сборка
  падает обратно на отладочный ключ, так что проект собирается и без него.
- `key.properties`, `*.jks`, `*.keystore` добавлены в `.gitignore`.
- Из манифеста убрано `USE_EXACT_ALARM` — Play разрешает его только будильникам
  и календарям. Осталось `SCHEDULE_EXACT_ALARM`, которое пользователь выдаёт сам
  (приложение просит его на шаге настройки уведомлений).
- Убрано `ACCESS_FINE_LOCATION` — для определения города достаточно
  приблизительного, а точное потребовало бы отдельного обоснования.
- Ассеты для карточки: значок 512×512, картинка функции 1024×500,
  5 скриншотов 1200×2400 (Play не принимает соотношение выше 2:1, поэтому
  снимки 1080×2400 положены на холст с полями).
- Тексты карточки на русском, английском и узбекском.
- Политика конфиденциальности в `.md` и готовом к публикации `.html`.

## Сколько это стоит

- **Регистрация разработчика — 25 долларов, один раз за всё время.**
- Публикация приложений и обновлений — бесплатно, количество не ограничено.
- Комиссия Google — только с платных приложений и покупок внутри. У вас
  бесплатное приложение без покупок, значит комиссии нет.
- GitHub Pages для политики — бесплатно.

Итого: **25 долларов один раз**, дальше ничего.
